## Code ported from the owner's earlier projects

- The 3D room in `src/room/`, `src/components/`, `src/video/ease.ts`, `src/browserStorage.ts`, `src/i18n/`, `src/world.css` and the room modules in `shared/` come from PA Cafe (`pa-cafe/pa-cafe`, branch `s10-studio-desk`, commit `a48a6b66`), cut down to the showroom. `src/room/furnitureModels.ts` and everything in `src/cart/` are new.
- `tools/meta-hackathon/probe/` comes from agentic-remotion-studio (`dnplus/agentic-remotion-studio`, branch `meta-hackathon/2026`, commit `0a0bc75`), cut down as their headers say.

Both projects have the same owner as this repository, and the ported code is included under this repository's Apache-2.0 license.

## Original to this repository

- `public/studio/showroom-set.glb`, the presenter studio set, is PA Cafe's `public/creator/presenter.glb` (the #582 studio set, `pa-cafe/pa-cafe` branch `self-media-room`, commit `7cd1b461`), byte for byte (sha256 `d8a1cbaf001b6b0b5a7cdbe0a9f28056fa92865d9d612c8e0e2f160a3111d162`). It comes from the owner's own PA Cafe streamroom module assets.
- `runner/composition/plates/*.png` (`close-back.png`, `close-front.png`, `wide-back.png`, `wide-front.png`) are background plates shot from that same streamroom set by `scripts/promo-plates.mjs`, so they also come from the owner's own PA Cafe streamroom module assets.
- On 2026-11-04 the owner confirmed that the streamroom set and these plates are their own work and agreed to release them under this repository's Apache-2.0 license.
- The product boxes and their picture cards are drawn in code by `src/cart/cartScene.ts`; `src/room/furnitureModels.ts` keeps box stand-ins for a furniture model that fails to load. Apache-2.0.
- `docs/screenshots/*.png` are screenshots of this app made by `scripts/screenshots.mjs`. Apache-2.0.
- The 圍裙店員 and 帽子店員 clerks and the plain stand-in figures used when no art loads are drawn in code as SVG by `src/room/characterArt.ts` and `src/room/silhouette.ts`. Apache-2.0. They are neutral figures: no character, logo or mascot of any company, and nothing was copied from another project's art.
